
# Personal Expense Tracker (Python)

Hello! I am a Technical High School student specializing in Information Technology and Software Development, with a strong interest in programming, automation, and software engineering.

This repository features my **Personal Expense Tracker**, a command-line application developed with Python. The project demonstrates my understanding of fundamental programming concepts, structured code, input validation, and data management.

## Key Features & Software Architecture

- **Interactive Command-Line Interface:** Provides a menu-driven experience that allows users to manage expenses directly through the terminal.
- **Expense Management:** Allows users to add expenses by entering a description and an amount.
- **Input Validation:** Handles invalid numerical inputs and prevents empty expense names or non-positive amounts from being accepted.
- **Real-Time Expense Calculation:** Calculates and displays the total amount of expenses recorded during the current session.
- **Expense Listing:** Displays recorded expenses with their names and formatted amounts.
- **Modular Code Structure:** Uses separate functions to organize the program into manageable and reusable components.
- **Error Handling:** Uses `try-except` to handle invalid numerical input without unexpectedly terminating the program.

## Core Features

- Add a new expense
- View all recorded expenses
- Calculate total spending
- Validate user input
- Navigate an interactive menu
- Exit the application safely

## Tech Stack

- **Language:** Python
- **Concepts:** Functions, Lists, Dictionaries, Loops, Conditional Statements, Exception Handling, Input Validation
- **Tools:** Visual Studio Code, Git, GitHub

## How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository or download the project files.
3. Open a terminal in the project directory.
4. Run the following command:

```bash
python main.py
```

## Current Limitations

- Expenses are stored in memory and are not permanently saved.
- Recorded data is lost when the application closes.
- The application currently runs in the terminal.
